# IELTS Listening Lab

Free IELTS Listening practice in the computer-delivered format.

- 20 full-length tests (about 30 minutes each), 40 questions per test
- Four levels: Foundation, Intermediate, Advanced and Expert
- Audio is read aloud by the browser's built-in voices at 1.15x speed, with a different voice for each speaker
- Reading time before each part, 30 seconds to check after Parts 1-3, 2 minutes at the end, then automatic submission
- Highlighting, question flags and a question navigator, as in the real test
- Band score, score by part and question type, mistake analysis, and the transcript line for every answer

For the most natural voices, open the site in Microsoft Edge on Windows.

These are original practice tests written in the Cambridge style. They are not official IELTS or Cambridge material. Scores are saved in your own browser only.

## Run it

It is a single `index.html` file with no build step. Open it in a browser, or host it with GitHub Pages.
